# Portfolio

Your assessment evidence lives here and in `build/`.

- `reports/` is written by `python -m sslab`. Commit every run; do not edit generated reports.
- `student.toml` holds your name, private repo and lab range (created in week 12).
- `reflection.md` is yours, copied from `templates/reflection.md` in week 15 and finished in week 17.

## Templates

`templates/` holds starting points for the documents you write. Delete the prompts you have answered, keep the headings, and write in your own words. Where you used an AI tool, say so in one line.

| Template | Save it as | Used in |
| --- | --- | --- |
| `consultation-record.md` | `portfolio/consultations.md` | Talking to the client (weeks 1 to 3) |
| `design-report.md` | `portfolio/design.md` | Design (week 3) |
| `work-plan.md` | `portfolio/work-plans/<name>.md` | Any work another person may repeat |
| `test-plan.md` | `portfolio/test-plan.md` | Prototype and testing (week 8), retest (week 17) |
| `change-and-disruption-notice.md` | `portfolio/change-notice.md` | Before disruptive work (week 8) |
| `signoff-request.md` | `portfolio/signoff.md` | Asking for approval or feedback (weeks 8, 14, 18) |
| `security-design.md` | `portfolio/security-design.md` | Security design (week 14) |
| `security-policy.md` | `portfolio/policies/<name>.md` | Policies (week 14) |
| `ir-runbook.md` | `portfolio/incident-runbook.md` | Incident response (week 18) |
| `handover-pack.md` | `portfolio/handover/` | Handover (week 18) |

The threat model, risk register, evidence log, manager briefing and reflection templates are used in weeks 12 to 17.

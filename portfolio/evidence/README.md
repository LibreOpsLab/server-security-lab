# Evidence

One folder per build guide, named after the guide: `01-prepare-the-workstation`, `02-pfsense`, and so on.
Each folder holds an `evidence.md` (copied from `portfolio/templates/evidence-log.md`) plus the screenshots
and text files it refers to.

Your assessor marks a guide as complete when its folder shows three things: **it worked** (proof), **you
did it** (your name, your hostnames, your dates), and **you understood it** (your own words). The
[evidence rules](../../docs/build/00-welcome.md#evidence-what-to-capture-and-how) explain how.

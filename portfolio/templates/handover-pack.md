# Handover pack

Use this when you hand the platform to the person who will run it next.

## 1. Server configuration
Per server: role, address, operating system and version, services, how to start and restart them, config file locations, and links to the repo.

## 2. Server status
Current state of each service and check, open issues, accepted risks, and the monitoring and backup status.

## 3. Operational changes
| Date | Change | Reason | Who | Test result |
| --- | --- | --- | --- | --- |

## 4. Documentation report
An index of every document with its version and location.

## 5. Status notification (to the owner)
Date, to whom, what was said, and the response.

## 6. Clean-up record
| Item | Restored or removed | Evidence (screenshot or photo pasted here) |
| --- | --- | --- |

Include restoring any protections switched off for the lab (for example the Windows features turned off in week 1).

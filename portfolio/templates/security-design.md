# Security design

Use this for the security design of the platform: the phases, the measures for each component, and how you will check each one.

## 1. Planning phase
What is decided before building: scope, assets (link the register), threats (link the threat model), requirements, who approves.

## 2. Building phase
Order of work, owners, dependencies, and the check that proves each control works before it is relied on.

## 3. Managing phase
Monitoring, what is logged and alerted on, patching, the review cycle, and incident response (link the runbook).

## 4. Attacker scenarios
For each scenario, step by step: the step, the control that should stop it, and what you would see.
Mark any step with no control or nothing to see as a gap, and say how it closes.
